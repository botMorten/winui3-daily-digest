## Community experience

- **FluentCleaner makes its WinUI UI adaptive without code-behind.** Belim’s **November 26** release, 26.11.126, replaces a 777-line settings page with smaller `Frame` pages sharing a ViewModel. It uses `VisualStateManager` plus one `AdaptiveTrigger` to switch details between a side column and an overlay, while fixing independently scrolling cookie lists and missing per-entry cleaning progress. This is a concrete shipping-app example of XAML layout and feedback polish, not a framework benchmark. **Missed coverage**, not a new release today; its November 28 update timestamp alone does not establish what changed. <https://github.com/builtbybel/FluentCleaner/releases/tag/26.11.126>

- **Missed coverage: accessibility and dangerous defaults in the same app.** FluentCleaner 26.11.123, published **November 22 Pacific / November 23 UTC**, says Narrator now announces control names instead of only “checkbox” or “toggle button.” More urgently, the developer reports that enabling its optional **Winapp3 cleaning-rule database** previously selected dangerous rules and one user lost apps; defaults are now safer, but existing selections remain until users restore defaults. **Winapp3 here is not WinUI 3.** These are application fixes, not evidence of a WinUI framework defect. <https://github.com/builtbybel/FluentCleaner/releases/tag/26.11.123>

- **Push deployment catch-up: a resolution with a very specific boundary.** In WindowsAppSDK issue #6574, originally opened **June 21**, a **November 26** contributor follow-up reports resolving an **MDM push** authentication problem using Store-app credentials, plus using a one-byte body when empty raw payloads were dropped. Another user still reports HTTP 403. This is reporter-tested progress, **not** a general fix for WinUI/SDK push: the currently inspected SDK quickstart still requires PFN mapping and does not support Partner Center credentials for its documented Entra route. Do not transplant the MDM workaround into that flow. <https://github.com/microsoft/WindowsAppSDK/issues/6574#issuecomment-7190812172> · <https://learn.microsoft.com/en-us/windows/apps/develop/notifications/push-notifications/push-quickstart>
